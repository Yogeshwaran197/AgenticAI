A multi-agent AI system built with LangChain.

```

├── src/
│   ├── agents/
│   │   ├── __init__.py

│   ├── pipelines/

│   ├── tools/

│   │   └── tools.py
│   └── __init__.py
├── .gitignore
├── LICENSE

├── app.py
├── main.py
└── requirements.txt
```

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python main.py
   ```

3. Or launch the Streamlit UI:
   ```bash
   streamlit run app.py
   ```
